# Certificates Repository

A centralized, structured repository containing professional certifications, organized for easy management and versioning.

## Naming Convention

All files follow a standardized naming convention:
`issuer-certificate-name-yyyy-mm-dd.ext`

- **Lowercased**: All filenames are in lowercase.
- **Hyphens**: Spaces and special characters are replaced by hyphens.
- **PT-BR/EN**: Portuguese certificates maintain their PT-BR names, while English ones (like SoloLearn) use English.
